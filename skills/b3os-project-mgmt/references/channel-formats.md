같은 사실을 채널마다 다른 ★모양★으로 낸다. 내용은 TODO.md 에서 만든다. 아래 예시는 가상 프로젝트 "Ledger" 다.

## 텔레그램 1:1 — 정리

★상태별 섹션 + 항목 앞에 같은 상태 아이콘 반복★ 이 실측에서 제일 잘 읽혔다. 구획마다 다른 아이콘을 다는 쪽은 읽기 어렵다는 반응이었고, 아이콘을 다 빼고 굵은 제목만 남긴 쪽은 원하는 모양이 아니라는 반응이었다.

```
✦ Ledger 지금 상황입니다.

━━━━━━━━━━━━━━━━━━━━
🎯 ★지향 · 목표★
━━━━━━━━━━━━━━━━━━━━
🎯 영수증을 찍기만 하면 → 분류·보관·세무 자료
🎯 1. 입력 전 과정이 카메라 한 번으로 ← 지금
🎯 2. 월별 자료 → 세무사 포맷 (킵)

━━━━━━━━━━━━━━━━━━━━
🟥 ★고치는 중 · 우선순위 1★ (1)
━━━━━━━━━━━━━━━━━━━━
🟥 영수증 인식 정확도 — A 구현 · B 검사 · PR #12 병합 전

━━━━━━━━━━━━━━━━━━━━
✅ ★드린 앱에 있음★ (12)
━━━━━━━━━━━━━━━━━━━━
카메라 진입 · 분류 규칙 · 설정 화면

━━━━━━━━━━━━━━━━━━━━
⚪ ★킵 · 팀장님이 미루신 것★ (3)
━━━━━━━━━━━━━━━━━━━━

👆 ★눌러봐 주셔야 하는 것★ (2)
━━━━━━━━━━━━━━━━━━━━
👆 실기기 카메라
👆 어두운 조명
```

규칙
- 첫 줄 `✦ <프로젝트> 지금 상황입니다.` 그 다음부터 상태별 구획
- 구획 = `━━━` 줄 · `아이콘 ★제목★ (건수)` · `━━━` 줄. 구획 순서: 🎯 지향·목표 → 🟥 고치는 중 → 🟩 고쳤음·아직 안 드림 → ✅ 드린 앱에 있음 → ⚪ 킵 → 👆 손 검증 (없는 구획은 뺀다)
- 항목 앞에 ★그 구획의 아이콘을 반복★ (🟥 🟩 ⚪ 👆). ✅ 구획만 예외 — 건수가 많아 아이콘 없이 ` · ` 로 잇는다
- 항목 한 줄. 키·명령은 백틱 없이 그대로(텔레그램에서 백틱은 읽기를 방해한다)
- 표는 안 쓴다 (텔레그램이 못 그린다)

## 텔레그램 1:1 — todo 리스트 ("todo 리스트 줘" · 중간 목록)

팀장이 "todo 리스트 줘" 라고 하면 이 모양으로 낸다. 정리 포맷(━━━ 구획)과 다르다 — ★영역별 머리 + 번호 이어 매김 + 줄 끝 상태★.

```
네, 전부 끝내고 검증본으로 드리겠습니다. 19:57 기준 중간 목록입니다.

[버그·기본 — 1.2]
1. 영수증 두 장 찍으면 두 번째가 덮어씀 — 고침·합침 ✅
2. 월 바뀔 때 합계가 0 으로 보임 — 진행 중 (최우선)
3. 설정 창이 안 뜸 — 재현·수정 중

[분류 규칙 — 1.2]
4. 가게 이름으로 자동 분류 — 합침·앱 확인 ✅

[1.2 출시]
5. 출시 검사+공증 — 20:03 시작, 20:20 전달 목표

[1.3 — 이어서]
6. 세무사 포맷 내보내기 — 구현 중(B)

[나중]
7. 은행 연동 — 킵

❓ 결정 대기
• 영수증 원본 보관 기간
```

규칙
- 첫 줄 = 답 한 줄(무엇을 언제 주는지) + "HH:MM 기준 중간 목록입니다."
- 머리 = `[영역 — 버전]`. 영역은 버그·기본이 맨 위, 그다음 기능 영역, `[버전 출시]`, `[다음 버전 — 이어서]`, `[나중]` 순
- 번호는 머리를 넘어 ★이어 매긴다★ — "7번 어떻게 됐어?" 로 바로 가리킬 수 있게
- 한 줄 = 증상·기능(사용자 말로) + ` — 상태`. 상태 말: `고침·합침 ✅` · `합침·앱 확인 ✅` · `진행 중` · `재현·수정 중` · `대기(누가)` · `킵`. 잰 근거가 짧으면 괄호로(`568KB 44→12ms`)
- 완료 표시 ✅ 는 ★잰 것만★. 못 잰 것은 ✅ 없이 "앱 확인 전" 처럼 쓴다
- 끝에 `❓ 결정 대기` — 팀장이 정해야 하는 것만. 없으면 뺀다
- 표·백틱은 쓰지 않는다

## 텔레그램 1:1 — 진행 알림 · 짧은 답

두 줄. 상세는 PR·TODO.md 에 있으니 다시 적지 않는다.
```
분류 규칙 → PR #12 올림, B 리뷰 중, 승인 뒤 머지.
```
- 답 먼저. 3~5줄. 맥락은 그 뒤 한 문단
- 숫자로 — "12건 중 10건 닫힘 · main abc1234"
- 못 잰 것은 "못 쟀다" 고 쓰고 ★눌러볼 것★으로 넘긴다
- 배포본은 `files:` 로 첨부. 전후 사진은 "위가 전 · 아래가 후" 를 적는다
