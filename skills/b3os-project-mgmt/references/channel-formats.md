# 채널별 보고 포맷 — 정본

같은 사실을 채널마다 다른 ★모양★으로 낸다. 내용은 TODO.md 에서 만든다. 아래 예시는 가상 프로젝트 "Ledger" 다.

## 텔레그램 1:1 — 정리

섹션 제목만 굵게, 항목은 `·` 한 줄. 섹션마다 아이콘을 달면 정신없다는 답이 온다 — 아이콘은 안 쓰거나 최소.

```
**Ledger · 9/13**

**지향** 영수증을 찍기만 하면 → 분류·보관·세무 자료로 이어지는 가계부

**목표**
1. 입력 전 과정이 카메라 한 번으로 ← 지금
2. 월별 자료 → 세무사 포맷 (킵)

**구조** 사진 원본 보존 · 분류는 덧붙임 · 키는 키체인

**진행 중**
· 영수증 인식 정확도 — A 구현 · B 검사

**완료 (이번 주)**
· 인식 결함 12건 · 카메라 진입 · 분류 규칙 · 설정 화면

**킵**
· 디자인 리서치 · 은행 연동 · 내보내기

**손 검증** 실기기 카메라 · 어두운 조명
```

규칙
- 고정 순서: 지향 · 목표 · 구조 · 진행 중 · 완료 · 킵 · 손 검증 (없는 섹션은 뺀다)
- 항목 = `·` 한 줄. 진행 표시는 `← 지금` / `(킵)`
- 키·명령은 백틱. 설명은 넣지 않는다 — 물으면 따로 답한다
- 텔레그램은 markdown 표를 못 그린다. 표 대신 항목

## 텔레그램 1:1 — 진행 알림 · 짧은 답

두 줄. 상세는 PR·TODO.md 에 있으니 다시 적지 않는다.
```
분류 규칙 → PR #12 올림, B 리뷰 중, 승인 뒤 머지.
```
- 답 먼저. 3~5줄. 맥락은 그 뒤 한 문단
- 숫자로 — "12건 중 10건 닫힘 · main abc1234"
- 못 잰 것은 "못 쟀다" 고 쓰고 ★눌러볼 것★으로 넘긴다
- 배포본은 `files:` 로 첨부. 전후 사진은 "위가 전 · 아래가 후" 를 적는다
