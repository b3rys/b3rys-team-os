규칙
- 섹션 헤더 = 아이콘 + 굵은 제목. 고정 순서: 📝 🎯 🏁 🧱 📏 🔄 ✅ 📌 🐛 👥 🖐 (없는 섹션은 뺀다)
- 항목 = `•` 한 줄. 진행 표시는 `← 🔄 지금` / `← 📌 킵` / `⚠️`
- 키·명령은 백틱. 설명은 넣지 않는다 — 물으면 따로 답한다
- 텔레그램은 markdown 표를 못 그린다. 표 대신 항목
