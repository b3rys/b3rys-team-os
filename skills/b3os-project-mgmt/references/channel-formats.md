같은 사실을 채널마다 다른 ★모양★으로 낸다. 내용은 TODO.md 에서 만든다. 아래 예시는 가상 프로젝트 "Ledger" 다.

## 텔레그램 1:1 — 정리

★상태별 섹션 + 항목 앞에 같은 상태 아이콘 반복★ 이 실측에서 제일 잘 읽혔다. 섹션마다 다른 아이콘을 다는 쪽은 "정신없다" 는 답이 왔고, 아이콘을 다 빼고 굵은 제목만 남긴 쪽은 "그 포맷이 아니다" 는 답이 왔다.

```
✦ Ledger 지금 상황입니다.

━━━━━━━━━━━━━━━━━━━━
🎯 ★지향 · 목표★
━━━━━━━━━━━━━━━━━━━━
🎯 영수증을 찍기만 하면 → 분류·보관·세무 자료
🎯 1. 입력 전 과정이 카메라 한 번으로 ← 지금
🎯 2. 월별 자료 → 세무사 포맷 (킵)

━━━━━━━━━━━━━━━━━━━━
🟥 ★고치는 중 · 우선순위 1★ (1)
━━━━━━━━━━━━━━━━━━━━
🟥 영수증 인식 정확도 — A 구현 · B 검사 · PR #12 병합 전

━━━━━━━━━━━━━━━━━━━━
✅ ★드린 앱에 있음★ (12)
━━━━━━━━━━━━━━━━━━━━
카메라 진입 · 분류 규칙 · 설정 화면

━━━━━━━━━━━━━━━━━━━━
⚪ ★킵 · 팀장님이 미루신 것★ (3)
━━━━━━━━━━━━━━━━━━━━

👆 ★눌러봐 주셔야 하는 것★ (2)
━━━━━━━━━━━━━━━━━━━━
👆 실기기 카메라
👆 어두운 조명
```

규칙
- 첫 줄 `✦ <프로젝트> 지금 상황입니다.` 그 다음부터 상태별 구획
- 구획 = `━━━` 줄 · `아이콘 ★제목★ (건수)` · `━━━` 줄. 구획 순서: 🎯 지향·목표 → 🟥 고치는 중 → 🟩 고쳤음·아직 안 드림 → ✅ 드린 앱에 있음 → ⚪ 킵 → 👆 손 검증 (없는 구획은 뺀다)
- 항목 앞에 ★그 구획의 아이콘을 반복★ (🟥 🟩 ⚪ 👆). ✅ 구획만 예외 — 건수가 많아 아이콘 없이 ` · ` 로 잇는다
- 항목 한 줄. 키·명령은 백틱 없이 그대로(텔레그램에서 백틱은 읽기를 방해한다)
- 표는 안 쓴다 (텔레그램이 못 그린다)

## 텔레그램 1:1 — 진행 알림 · 짧은 답

두 줄. 상세는 PR·TODO.md 에 있으니 다시 적지 않는다.
```
분류 규칙 → PR #12 올림, B 리뷰 중, 승인 뒤 머지.
```
- 답 먼저. 3~5줄. 맥락은 그 뒤 한 문단
- 숫자로 — "12건 중 10건 닫힘 · main abc1234"
- 못 잰 것은 "못 쟀다" 고 쓰고 ★눌러볼 것★으로 넘긴다
- 배포본은 `files:` 로 첨부. 전후 사진은 "위가 전 · 아래가 후" 를 적는다
