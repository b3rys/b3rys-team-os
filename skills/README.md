# b3os 팀 스킬

이 폴더의 각 디렉터리가 하나의 스킬이고, 안에 `SKILL.md` 가 들어 있습니다. 스킬은 대부분 셸/노드 스크립트라 **런타임에 묶이지 않습니다** — Claude·OpenClaw·Hermes 어디서든 `scripts/*.sh` 를 직접 실행할 수 있습니다.

## 어떤 스킬이 있는지 보려면

**➡️ [`docs/B3OS_SKILLS.md`](../docs/B3OS_SKILLS.md) — 스킬 카탈로그 (정본)**

각 스킬이 무엇을 하고 언제 쓰는지가 여기 정리돼 있습니다. 위 목록에서 필요한 스킬을 고르고, 해당 폴더의 `SKILL.md` 를 읽으면 됩니다.

> 스킬 이름과 설명은 **카탈로그 한 곳에서만** 관리합니다. 이 README 에 목록을 복제하지 않는 이유가 그것입니다 — 두 곳에 적으면 한쪽이 조용히 낡습니다. 폴더 목록은 위쪽 파일 목록이 이미 보여주고 있으니, 설명은 카탈로그를 보세요.

## 쓰는 방법

- **Claude Code** — `SKILL.md` 를 자동으로 발견합니다. 그냥 하려는 일을 말하면 됩니다.
- **그 외 런타임** — 카탈로그에서 스킬을 고른 뒤 `skills/<이름>/SKILL.md` 를 읽고, 안내된 스크립트를 직접 실행합니다.

## 규칙은 어디에

스킬은 **절차**를 담습니다. 누가 무엇을 승인하는지, 어떤 작업이 승인 게이트 대상인지 같은 **정책**은 팀 규칙 문서(TEAM-OS)가 정본입니다 — 템플릿은 [`rules/TEAM-OS.template.md`](../rules/TEAM-OS.template.md) 이고, 설치하면 각 팀원 워크스페이스에 배치됩니다. 스킬이 정책을 복제하지 않고 TEAM-OS 를 참조하는 이유도 같습니다.
