# 긴 보고서 탭 나누기

본문이 15,000자를 넘거나 그림이 20장을 넘으면 나눈다. 짧은 보고서와 탭 둘뿐인 보고서는 나누지 않는다. 안 나누면 목차 링크가 엉뚱한 자리에 선다(아래쪽 SVG 가 뒤늦게 자리를 잡아 내용이 밀린다).

MD 에 표식 한 줄을 넣는다. 이 줄부터 다음 표식 전까지가 한 탭이다.

```markdown
<div id="p0" data-tab="0부 구조"></div>

## 0부 — LLM 이 문장을 처리하는 순서
...
<div id="p1" data-tab="1부 학습"></div>
```

- `id` 는 탭 주소다. `#p0` 과 `#panel-p0` 둘 다 열린다.
- `data-tab` 은 탭 글자다. 한 줄에 들어가게 짧게 쓴다(`0부 구조` 가능, `0부 구조 — LLM 이 문장을 처리하는 순서` 불가).
- 첫 표식 위의 내용은 탭 밖에 남는다. 제목·리드·전체 요약을 둔다.
- 표식은 한 줄로 닫는다. 여러 줄이거나, `id`·`data-tab` 중 하나가 없거나, id 가 겹치거나, 표식이 1개뿐이면 렌더가 멈춘다.

## 전환 방식

- 전환은 CSS `:target` 이다. `/reports` 뷰어는 `sandbox` iframe 으로 스크립트를 막으므로(`Reports.ts`) 자바스크립트만으로는 탭이 죽는다. 생김새는 `theme.css` 의 `.report-tabs`/`.report-tab` 을 쓴다(`references/ui-components.md` 2절).
- 스크립트가 켜지면 `.wrap` 에 `js-tabs` 를 붙여 `:target` 규칙을 끈다. 둘이 같이 살아 있으면 패널이 둘 보인다.
- 탭을 눌러도 화면을 옮기지 않는다. 클릭을 가로채(`e.preventDefault()`) 패널을 클래스로 바꿔 끼우고, 주소는 `history.replaceState(null,'','#tab=<이름>')` 로 바꾼다. 화면을 따라다니며 고치는 코드는 sticky 경계 어긋남·음수 좌표·복원 위치 밀림 같은 결함을 낳는다.
- `#어느-장` 으로 깊이 들어온 경우만 패널을 켠 뒤 한 번 옮긴다(좌표는 패널을 켠 뒤에 정해진다). `scrollTo` 는 이 한 곳뿐이고 `window.scrollTo({top, behavior:'instant'})` 형태다. 2인자 `scrollTo(x, y)` 는 `theme.css` 의 `scroll-behavior:smooth` 때문에 화면을 못 움직이는데 에러도 없다.
- `requestAnimationFrame` 은 배경 탭(`document.hidden === true`)에서 콜백이 실행되지 않으므로 쓰지 않는다. 코드가 안 도는데 화면이 비슷해 동작하는 것처럼 보인다.

## 배포 전 검사 (브라우저에서 직접)

`render.test.mjs` 는 구조만 본다. 아래 넷은 브라우저에서 잰다.
1. 깊은 주소로 바로 열기(`...#p3-5`): 그 탭이 켜지고 그 절이 화면 위에 오나
2. 탭 클릭: 탭 줄이 화면 위에 오나
3. 목차 링크 전부: `href="#x"` 대 `id="x"` 대조
4. 첫 진입(해시 없음): 첫 탭이 켜지나

## 실제 열람 경로 검증

목차 대상 `id` 가 있는 것은 정적 검사일 뿐 클릭 성공의 증거가 아니다. 포털과 단독 HTML을 나눠 검사한다. Mac 문제가 보고됐다면 WebKit 에서도 확인하되 Safari 앱 검증이라고 쓰지 않는다.
- 목차에서 앞·중간·끝 절과 다른 탭 안의 절로 이동했을 때 제목이 보이나
- 깊은 링크 첫 진입·새로고침·뒤로가기(iframe 내부 주소와 바깥 포털 주소를 혼동하지 않는다)
- 글꼴·그림 로딩 뒤 위치가 밀리나, 좁은 화면·확대 상태에서 읽히나
- 숨은 심화 탭을 읽지 않아도 본문이 이해되나
- 미재현은 해결이 아니다. 브라우저·경로·실행한 동작과 미검증 범위를 기록하고, 환경을 모르면 확인 가능한 경로부터 검사한다.
