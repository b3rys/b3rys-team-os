# 표현 리뷰 (3단계 팀원 리뷰용)

표현 리뷰를 글쓴이가 대신할 수 없다. 몇 시간 한 주제를 보면 자기가 지어낸 말이 자기에게는 분명하게 읽힌다. 맥락이 없는 팀원이 같은 문장에서 걸린다.

| 갈래 | 예 | 빠진 것 |
|---|---|---|
| 글쓴이가 지어낸 말 | `화면이 6,180px 떨어진 곳에 선다` | 표준 용어나 화면에 보이는 이름을 쓴다 |
| 가리키는 것을 안 밝힘 | `코드가 있으면 제자리입니다` | 어디가 제자리인지 글에 없다 |
| 성분이 빠진 토막 | `여섯 다 잡혔습니다` | 무엇이 무엇을 잡았는지 없다 |
| 문장이 아닌 명사 나열 | `탭 클릭 시 탭 줄이 화면 위` | 서술어가 없다 |
| 사물을 사람처럼 | `이 검사는 그 단어가 있는지만 봅니다` | 무엇이 무엇을 하는지로 쓴다 |

어느 갈래도 특정 단어로 걸러지지 않는다. `그 코드`·`그 값`·`그 장` 같은 지시관형사가 한 문단에 여러 번 나오면 이름으로 바꾼다.

- 걸리는 문장은 그대로 인용해서 돌려준다. 글쓴이는 왜 그렇게 썼는지 답하고 고친다.
- "짧게 줄여라"는 처방이 아니다. 줄이면 주어와 목적어부터 지워져 같은 결함이 다시 난다. 줄이는 것은 문장이 아니라 항목 수에서 한다.
- 자동 검사(`humanize-korean`)는 이 갈래를 못 잡는다. 위 예문도 위험도 낮음(2점)이 나온다. 사람이 읽는 단계를 대신하지 못한다.
